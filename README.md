# Rigly Releases

Public downloads and the [Sparkle](https://sparkle-project.org) update feed for **Rigly**, a macOS animation library and retargeting tool for Godot.

- **Downloads:** see [Releases](https://github.com/memfrag/Rigly-Releases/releases).
- **Update feed:** [`appcast.xml`](appcast.xml), read by the app from
  `https://raw.githubusercontent.com/memfrag/Rigly-Releases/main/appcast.xml`.

The app's source lives in a separate private repository; this one only carries release
builds and the appcast.
